# Komi / Comii 漫画阅读系统 — 部署与使用手册

> 版本：v2.1（本地离线下载 + 文件夹浏览修复）
> 更新：2026-11-12

---

## 一、系统架构

```
┌─────────────────────────────────────────────────────┐
│  Komi 容器 (Docker)                                  │
│  ├─ FastAPI 后端 (app.py)                            │
│  │    ├─ WebUI  : 8000  (页面 + 完整 API)            │
│  │    └─ API    : 8001  (仅 /api/*)                  │
│  ├─ 漫画库: /app/library/  (宿主机挂载 /srv/komi/library)│
│  └─ 下载区: /app/pawchive  (宿主机挂载 /srv/pawchive)  │
└─────────────────────────────────────────────────────┘
```

- **WebUI 端口**：8000 —— 浏览器访问漫画库
- **数据接口端口**：8001 —— 仅供 App/脚本调 `/api/*`
- **漫画库目录**：`/srv/komi/library/`（宿主机，已挂载进容器）
- **pawchive 下载区**：`/srv/pawchive/`（宿主机，已挂载进容器）

## 二、部署步骤

### 1. 构建镜像
```bash
cd /srv/komi
docker compose up -d --build
```

### 2. 代码热更新（改代码后，不进镜像也可生效）
```bash
# 后端
docker cp app.py komi:/app/app.py && docker restart komi

# 前端
docker cp static/app.js komi:/app/static/app.js
docker cp static/style.css komi:/app/static/style.css
docker cp static/index.html komi:/app/static/index.html
docker restart komi
```

### 3. 验证
```bash
curl http://localhost:8001/api/tree        # 应返回 JSON 目录树
curl "http://localhost:8001/api/export?target=bontiage"   # 应返回 ZIP
```

## 三、API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/tree` | 目录树（三级：作者 → 系列 → 图片） |
| GET | `/api/export?target=<路径>` | 打包 ZIP 下载（target 支持作者或系列） |
| GET | `/api/stream?path=<路径>&page=<n>` | 分页取图（漫画阅读） |
| GET | `/api/video?path=<路径>` | 取视频信息 |

## 四、前端功能

### 顶部分类 Tab
- **全部**：显示所有内容（含作者文件夹，可点进去）
- **漫画**：仅显示漫画系列
- **视频**：仅显示视频系列

### 卡片操作
- **点卡片**：进入系列阅读（漫画）或播放（视频）
- **⬇ 下载按钮**（右上角）：打包当前系列 ZIP 存本地
- **编辑模式**（左上角切换）：
  - 多选 → **移动**（跨目录）
  - 多选 → **删除**
  - **长按卡片**：直接弹出移动选择

### 面包屑导航
- 根目录 › 作者 › 系列，点任意层级可返回。

## 五、pawchive 下载器（工作区脚本）

### 关键：分页参数
- ❌ `page` 参数 **已被服务端忽略**，只返回首页 50 帖
- ✅ **`o` 参数才是真正的 offset 分页**：`?o=0` `?o=50` `?o=100` ...
- 每页 50 帖，用 `o` 递增 50 直到返回 0 帖。

### 脚本清单
| 文件 | 说明 |
|---|---|
| `pawchive_dl_threaded.py` | 多线程下载器（`o` 分页 + ID 去重 + 标题续传） |
| `batch_dl.py` | 批量调度（剔除 Lost_Proxy，max=真实帖数） |
| `probe_and_clean.py` | 探测真实帖数 + 清理重复目录 |
| `pawchive_download_handbook.md` | 详细下载手册 |

### 已剔除作者
- `Evil_Rakashaka`：7z 视频包为主，用户明确跳过
- `Lost_Proxy`：用户要求剔除

## 六、Android App（Capacitor 工程）

位于 `komi_apk/`，用 Capacitor 打包 WebUI。

### 构建
```bash
cd komi_apk/android
./gradlew assembleDebug        # 输出 app/build/outputs/apk/debug/app-debug.apk
```

### 同步 web 资源到 APK
修改 `static/` 下的前端文件后，**需复制到 `komi_apk/www/`** 再构建：
```bash
cp /srv/komi/static/* /srv/komi/komi_apk/www/
```

### 已知构建问题
- JDK 21 + Android SDK 33 会报 `core-for-system-modules.jar` 的 jlink 错误。
  - 解法：用 JDK 17 构建，或降 Android 平台版本。

### APK 产物
- `Comii_v2.1.apk`（versionCode 3）—— 最新可安装版

## 七、同步守护（/tmp/sync_all.py）

每 60s 把 `/srv/pawchive/` 新下载内容同步进 `/srv/komi/library/`。
下载新资源后需重启：
```bash
pkill -f sync_all.py; nohup python3 /tmp/sync_all.py &
```
