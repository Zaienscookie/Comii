# Comii 2.26.0：相册化重构

## 变化

- **去掉「漫画 / 视频」划分**：不再有 `comic` / `video` 两个固定分类页，根目录就是相册列表。
- **相册可以嵌套**：相册就是真实文件夹，可以一直往下套（作者 → 系列 → 子系列）。
- **照片和视频混排**：同一个相册里图片和视频按网格排，视频带播放角标。
- **统一的 vivo 相册布局**：App 和 WebUI 都是「方块封面 + 名称 + 数量」的相册网格；进入相册后先列子相册，再列本相册的照片 / 视频。
- **去掉「按文件夹 / 全部图片」切换**：只有一套视图。
- **照片 / 视频支持长按多选**：App 长按进入多选，可批量「分享」或「删除」；WebUI 同理（浏览器支持时用系统分享，否则下载）。
- **顶部工具栏统一**：标签、刷新、新建相册、导入、回收站、编辑；WebUI 多一个主题切换。
- **下载页跟相册页一致**：同样是方块封面网格（分类作为筛选 chip）。

## 接口

- `browse` 返回 `kind = "album"` 节点（有子目录的目录），同时带自己的 `image_count` / `video_count` / `child_count`；叶子目录仍是 `manga` / `video` / `mixed`。
- 删除单张图片 / 视频：`POST /api/v1/media/delete {"path": "...", "names": [...]}`
  - 文件会移到 `data/trash/media/<时间>/<相册路径>/`，可在 NAS 上手工找回。
- WebUI 兼容层：`POST /api/media/delete`、`GET /api/tags`、`GET /api/tagged?tag=`

## 数据

文件系统不用迁移：原来的 `comic/`、`video/` 现在就是两个相册，R18 仍以只读方式挂在
`comic/R18`、`video/R18`。以后想合并成一个相册，只需在 NAS 上移动目录（注意只读挂载）。
