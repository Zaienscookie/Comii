# Comii AI（原生版，2.11.0）

> 入口：App 底部 **AI**；配置：**AI 右上角齿轮** 或 **设置 → AI 服务设置**
> 数据只存在手机本地，不上传服务器；覆盖安装/应用内更新不会删除

## 1. 结构

```
Persona 人格 → Conversation 会话 → Context（人格 + 自动记忆 + 插件 + 最近 N 条）
```

- 多个人格、每个人格多条独立会话
- 人格只保留：头像、名字、简介、system prompt、温度、插件、主动消息开关
- 开场白、长期记忆、主题色、城市/身份都不需要手填

## 2. 虚拟人生（自动）

开启「虚拟人生」插件后，**完全自动**：

- 进入聊天时如果当天还没有安排，会静默调用一次模型生成当天日程、心情、穿搭
- 生成内容会作为 system 注入每轮对话；聊天页默认只显示一行提示，点「查看日程」才展开完整安排
- 角色可以出门、见朋友、做自己的事，不限定城市/职业
- 不需要手动点「生成」或填写任何字段

## 3. 记忆（自动）

- 一条会话超过 30 条消息：自动把较早的对话压缩成 2–5 句写进长期记忆，只保留最近 10 条
- 长期记忆字段不再需要手动编辑
- **导出/导入**：AI 设置 →「导出 AI 数据（JSON）」/「从 JSON 导入」

## 4. 多模态

AI 设置里开启「多模态（发送图片）」后：

- 聊天框左侧出现图片按钮和相机按钮，可从相册选图或直接拍照
- 图片会压到最长边 1024、JPEG 82%，以 OpenAI Vision 格式（`image_url` + data URL）随当前消息发送
- 需要模型本身支持视觉；不开启时按钮隐藏

## 5. 分段回复

设置里开启「分段回复」后，模型会被要求用 `|||` 分隔多条短消息，
客户端拆成多个气泡，像真人连发；关闭则一条完整回复。

## 6. 连续消息合并

开启「合并连续消息」（默认开）后：

- 1.4 秒内连续发多条，会合并成一轮再请求模型
- 也可以关掉，每条立即回复

## 6. 好感度

- 每次发消息好感 +1（上限 100），显示在角色卡和聊天标题
- 纯本地数值，不需要配置

## 7. 主动消息

人格编辑页开启「主动发消息」，设置 1–24 小时间隔：

- 打开 App / 进入 AI 页时检查；实际触发时间在 0.7–1.6 倍间隔之间随机，不会像定时任务
- 提示词要求像真人随手发：分享刚做的事、吐槽、突然想到对方，避免固定问候
- 消息进入对应会话并弹系统通知
- 限制：App 被完全杀掉时不会触发（不是系统级定时任务）

## 8. 服务配置

OpenAI 兼容，只调用 `POST /chat/completions`，支持流式/非流式。

```
Base URL: https://yachiyo8000-maxtoken.pages.dev/v1
模型:     Yachiyo-v8000-flash
Key:      自己填，只存本机
```

## 9. 已知限制

- 没有工具调用 / 知识库 / Embedding
- 多模态依赖上游模型支持
- Key 明文存在 App 私有目录（demo 取舍）
