## 2. 本次改动逐条

1. **全选**
   - Comii 编辑模式：底部新增「全选 / 取消全选」。
   - 下载页编辑模式：同样支持全选；WebUI 编辑栏也加了「全选」。
2. **服务器地址历史**
   - 连接成功的地址自动记录（最多 8 条），设置/首次配置页可点选复用、右侧 × 删除，当前地址有「当前」标记。
3. **文件夹内新建**
   - 已在某个文件夹里时，新建只输入名称，不再问漫画/视频（类型继承上级）；
   - 创建成功后自动进入新文件夹，等待上传。
4. **上传页**
   - 「开始上传」固定在页面底部，选再多文件也不用滑到底。
5. **视频**
   - 文件夹页按钮按类型显示「全部视频 / 全部图片」。
   - 播放页左右滑动切换上一集/下一集，顶部显示「第 x / y 集」。
   - 默认静音，右上角一键开/关声音；设置里可改默认是否静音。
   - 倍速 0.5x–3x；可开关「音调跟随速度」（关则保持原音调）。
   - 单集循环播放（ExoPlayer REPEAT_MODE_ONE，无缝隙）。
   - 右上角可切换横屏 / 竖屏播放。
6. **相册序号**
   - 「全部」和文件夹的相册网格，左下角编号改为按显示顺序 1、2、3…（含分页续载）。
   - WebUI 相册同样显示顺序编号。
7. **WebUI 跟随 + 图标**
   - WebUI 编辑栏新增全选，相册显示序号；新增几何图标 `favicon.svg`。
   - App 图标换成新的几何书架图标（深色底 + 蓝色条纹）。
   - 版本号统一为 2.6.0。
8. **下载**
   - 下载弹层改为「后台下载 / 取消下载」；隐藏后顶部常驻进度条 + 取消按钮，不再和「后台」冲突。
   - 「全部」摊平列表同时包含视频（点视频直接播放），不再只有图片。
   - 下载页增加搜索框，布局与 Comii 一致（分类 / 全部、2 列卡片、编辑多选、全选）。
   - 视频下载沿用系列下载（图片 + 视频一起下载）。
9. **后台隐私**
   - 退到后台时界面自动模糊并显示「内容已隐藏」，同时加 FLAG_SECURE，最近任务里看不到内容；设置可关闭。
10. **启动内容提示**
    - 启动先显示 18+ 内容提示，确认后进入；设置 → 隐私 可关闭「启动内容提示」。
11. **下载页对齐 Comii**
    - 与 Comii 页一致的搜索、卡片网格、编辑/全选、分类与全部两种排列。

## 3. 服务端

- 版本号 2.6.0；`systemctl restart comii` 已生效。
- 接口无破坏性变更；仍为 WebUI 8000、数据接口 8001。
- 部署脚本：`tools/dev/deploy_frp.py`（从环境变量读取 SSH 密码，不落库）。

## 4. 已知限制

- WebUI 只做了核心跟随（全选、相册序号、图标、默认漫画），视频倍速/静音/后台下载仍以 App 为准。
- App 后台模糊在 Android 12+ 才有效果；低版本退化为「内容已隐藏」遮罩 + 禁止截图。
- 下载「后台」目前是应用内后台（切换页面继续下），不是系统通知栏常驻任务。
- 下载页与 Comii 页的视觉仍在逐步统一，个别间距/动画后续继续打磨。
